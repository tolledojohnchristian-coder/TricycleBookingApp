# Tricycle Booking

Tricycle Booking is an Expo React Native application for booking, managing, and monitoring tricycle ride records.

## Features

- User registration and login
- Local session checking on app launch
- Add, edit, delete, and cancel booking entries
- Toggle ride status between Pending and Completed
- Live search by pickup, destination, fare, date, or status
- Filter tabs for All, Pending, and Completed rides
- Dashboard statistics for Total Fare, Ride count, and Completed rides
- Form validation for empty fields and invalid fare values
- Local storage using AsyncStorage

## Run the app

```bash
npm install
npx expo start
```

Then open the app using Expo Go or an Android/iOS emulator.
